# Portfolio — Phạm Hồng Kim Hà (Jay)

React 19 + Vite + TailwindCSS + Framer Motion.

## Chỉnh thông tin cá nhân
- `src/constants/index.js` — tên, email, GitHub/LinkedIn/Figma, học vấn, giới thiệu
- `src/data/` — kỹ năng, chứng chỉ, kinh nghiệm, dự án
- `public/avatar.svg` — ảnh đại diện (thay bằng ảnh của bạn rồi đổi đường dẫn trong `HeroSection.jsx`)
- `public/resume.pdf` — thêm CV của bạn vào đây
- `index.html` — title, mô tả SEO, og:image

## Chạy
```
npm install
npm run dev
npm run build
```
